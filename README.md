# 🌍 Travel Website

A modern, fully responsive travel website built using HTML, CSS. This project showcases beautiful destinations, services, and an intuitive user experience — perfect for travel agencies or portfolio display.

## 🚀 Features

- 🖼️ Beautiful homepage with hero section
- 📱 Fully responsive (mobile, tablet, desktop)
- 📌 Services section with cards
- 📧 Contact form (frontend only)
- 🌐 Navigation bar and smooth scrolling
- 💡 Clean and modern design

## 🛠️ Tech Stack

- HTML 
- CSS3
